# justwatch-

Telegram Course Stream & PDF Notes Automation Bot (MTProto 2GB Engine).

## Features
- Full PDF Documents & Lossless Video Streams (.m3u8 / .mp4)
- 2,000 MB (2 GB) File Limit via MTProto Engine
- Interactive Resolution & Destination Quality Selector
- Persistent Deduplication Memory
- Render 24/7 Hosting Ready with internal health-check server

## Deployment
Configured for instant deployment on [Render](https://render.com) with native Docker and FFmpeg.
